# ContextPack — Codebase to LLM Prompt Packer

**Right-click any files or folders in VS Code, Cursor, Windsurf, or VSCodium to pack them into a clean, token-counted, secret-redacted prompt for ChatGPT, Claude, or Gemini.**

- **100% local & zero dependencies** — your code never leaves your machine.
- **Smart defaults** — automatically skips `node_modules`, `.git`, build folders, and binary assets.
- **Live token estimate** — instantly know how many tokens you just copied.
